# Página personal de Camilo Mayorga

Actividad de **Diseño de Sistemas en Internet** sobre la estructura básica del frontend mediante HTML.

## Descripción

Página personal de Camilo Javier Mayorga Vivas, estudiante de Ingeniería de Sistemas en la UNI. Incluye:

- Encabezado principal con el nombre.
- Párrafo de presentación personal.
- Lista de habilidades y cualidades.
- Imagen de perfil genérica.
- Enlaces a Facebook e Instagram.

## Archivos del proyecto

| Ruta | Contenido |
| --- | --- |
| `index.html` | Estructura y contenido de la página personal. |
| `css/styles.css` | Estilos y adaptación a pantallas pequeñas. |
| `js/app.js` | Archivo reservado y enlazado; la actividad no requiere lógica JavaScript. |
| `README.md` | Descripción e instrucciones del proyecto. |

## Cómo visualizar la página

Descarga el repositorio, conserva la estructura de carpetas y abre `index.html` en un navegador. También puedes abrirlo con Live Server desde Visual Studio Code.

No requiere instalación de paquetes. La imagen y los enlaces a redes sociales necesitan conexión a internet.
